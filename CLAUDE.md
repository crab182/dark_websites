# CLAUDE.md — dark_websites

Conventions for agents working on this repo.

## Hard rules

- **No GitHub Actions.** All automation is self-hosted by design. The weekly
  refresh is `scripts/weekly.sh` (run from cron); validation is the local
  pre-commit hook (`make hook`); deployment is branch-mode Pages / any static
  host with no build step. Do not add workflows under `.github/workflows/`,
  and close bot PRs that try to reintroduce them.
- **Review-bot findings: fix them yourself unless something else already
  has.** When Bugbot or another reviewer flags issues on a PR, apply the fixes
  directly on the PR branch, test them, and push. Only skip a finding when a
  fix for it has *verifiably* already landed on the branch (e.g. an autofix
  agent pushed it) — check the branch, don't assume. Decline duplicate or
  stale autofix patches silently.

## Working on the code

- The database is `data/sites.json`; everything under `data/` plus `feed.xml`,
  `FINDS.md`, and the README stats block is generated by `scripts/build.py` —
  regenerate, don't hand-edit.
- Scripts are stdlib-only Python 3 and POSIX sh; the portal is dependency-free
  vanilla JS. Keep it that way.
- Before pushing: `make validate` (or install the hook once with `make hook`).
- Facets are fixed: `obscure`, `niche`, `kitsch`, `broad`, `deep`, `narrow`.
  Every entry must be a legitimate, public website.
- Note for sandboxed sessions: `scripts/linkcheck.py` reports every URL as 403
  through the remote-execution proxy — don't commit `data/linkcheck.json`
  produced in a sandbox; keep the last real results.
